# Resources

Here's a list of stuff that might help you with your bot development!

**Websites:**
- [discohook.app] - Test messages and components.
- [regex101.com] - Test regex expressions.
- [ip-api.com] - Lookup an IP address.
- [singlecolorimage.com] - Test image dimensions.

**Libraries (PyPI):**
- [`asyncpg`] - Connect to PostgreSQL database.
- [`Pillow`] - Draw images.
- [`matplotlib`] - Draw graphs.
- [`orjson`] - Does JSON faster.
- [`NumPy`] - Do math efficiently in C code.
- [`psutil`] - Measure resources.
- [`pytest`] - Test stuff.
- [`uvloop`] - Faster loop (unix only).
- [`humanize`] - Format strings to be human readable.
- [`aiohttp`] - Make HTTP requests.
- [`lxml`] - Parse HTML and XML for scraping.
- [`feedparser`] - Parse RSS feeds.

**Astral's stuff:**
- [`uv`] - Package manager.
- [`ty`] - Type checker.
- [`ruff`] - Formatter.

**Deployment and monitoring:**
- [Docker] - Custom environments.
- [Sentry] - Track errors.
- [UptimeRobot] - Track uptime.

**Localhost tunnels:**
- [VSCode Port Forwarding] - Built-in VSCode extension, requires GitHub login.
    - **Usage:** Click `Ports` > `Forward a Port` > type the port number + set visiblity to `Public`.
    - **Example URL:** `https://abcdef-8000.euw.devtunnels.ms`
- [ngrok] - Requires account signup, free tier capped at 4,000 requests/min.
    - **Usage:** `ngrok http 8000`
    - **Example URL:** `https://random-words.ngrok-free.app`
- [Cloudflare Tunnels] - No account or login required.
    - **Usage:** `cloudflared tunnel --url http://localhost:8000`
    - **Example URL:** `https://random-words.trycloudflare.com`

**More VSCode extensions:**
- [Even Better TOML] - Support for `.toml` files.
- [Astro] - Support for `.astro` files.
- [MDX] - Support for `.mdx` files.
